# Space Wallpaper App

Space Wallpaper App is a Windows desktop application that finds real NASA space images, previews them, and turns them into high-resolution wallpapers for Windows.

## Highlights

- Real NASA image sourcing
- 2K-friendly wallpaper filtering
- Built-in preview window
- Optional caption rendered onto the wallpaper
- Daily random wallpaper on Windows startup
- Space-themed application icon
